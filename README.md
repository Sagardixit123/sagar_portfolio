# Sagar Dixit — Personal Portfolio

A responsive personal portfolio built with **HTML and CSS only**.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a repository named `Sagardixit123.github.io` (or use another repository name).
2. Upload `index.html`, `style.css`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.

For a user-site repository named `Sagardixit123.github.io`, the site will be available at:
`https://Sagardixit123.github.io/`

## Before publishing
- Add your project repository URLs when available.
- Add a PDF resume and link it from the hero section if you want a resume download button.
- Confirm that you are comfortable publishing your email address and phone number publicly.
